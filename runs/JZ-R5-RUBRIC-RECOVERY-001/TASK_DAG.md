# R5 Task DAG

```text
CP1 admission + official rubric + method calibration
 ├─ Wave A primary-source site evidence
 │   ├─ government/planning
 │   ├─ transport/institutions
 │   ├─ environment/fabric/heritage
 │   └─ source ledger -> fact pack -> problem atlas -> eight maps
 ├─ Wave B unchanged-premise rescore
 │   └─ site evidence + current peer corpus -> top four -> collision re-audit
 └─ Wave D formal toolchain rehearsal
     └─ script inspection -> scratch bootstrap -> validators -> readiness receipt

Wave B top four + Wave A evidence
 -> Wave C max two mini-schemes
 -> independent A/B jury
 -> Chief threshold decision
    ├─ no clear qualifier -> YELLOW or RED
    └─ one clear qualifier -> provisional Candidate 05 + neutral gates

All lanes
 -> deadline recovery plan
 -> terminal official delta
 -> return brief + owner decisions
 -> diff/status/ref verification + push
```

Only the root Implementer writes. Read-only supporting analysis may run concurrently, but finalist and promotion decisions are serialized through the evidence and scoring artifacts.
