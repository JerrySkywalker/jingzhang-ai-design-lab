# Competitive Landscape — Working Notes

**Status:** preliminary, must be refreshed from the live official repository before concept selection.

## Observed pattern

The field is already crowded with proposals built around:

- railway / track / line metaphors;
- AI urban operating systems and Agent governance;
- validation / calibration / evidence mechanisms;
- robotics and autonomous mobility testbeds;
- public-interface / fallback / human-review mechanisms;
- space/remote-sensing narratives;
- AI pulse / neural spine / digital-twin framings.

Therefore a new proposal cannot rely on vocabulary alone for differentiation.

## Benchmarks worth continuing to study

The prior sweep identified several useful *types* of benchmark:

- complete “symbiotic rail” packages that show how a distinctive mechanism can coexist with full urban-design coverage;
- robust/multi-world urban-evolution approaches that use a technical method to guide, rather than replace, urban design;
- verification/calibration proposals with explicit evidence and failure logic;
- robotics/public-service proposals that emphasize human fallback and operational reality;
- proposals with strong field/implementation critique rather than only visual branding.

Exact rankings, counts and review scores should be re-verified before being treated as current facts.

## Competitive lesson

A strong entry should combine:

**horizontal completeness** — a credible full urban design  
with  
**vertical depth** — one or more technically serious subsystems that other generic Agents cannot easily reproduce.

For Candidate 01, the provisional vertical depth is:

- embodied-AI public infrastructure;
- re-embodiment / service-hub logic;
- minimum-sufficient sensing;
- robust task/resource scheduling;
- degraded/fallback/human takeover design.

These are differentiators only if they materially change spatial, infrastructure and operational design decisions.
