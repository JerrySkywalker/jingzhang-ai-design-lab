# Benchmark Notes

Store one lightweight analytical note per selected peer proposal. Prefer text/evidence metadata first; fetch figures or PDFs only when materially necessary and licensing permits.

Each note should answer:

1. What is the proposal's complete urban-design mother concept?
2. How does it cover the three spatial scales?
3. What is genuinely distinctive versus generic generated content?
4. How are land use, buildings, mobility, blue-green/public space and the three key areas handled?
5. What evidence, assumptions and uncertainties are explicit?
6. What should we learn, and what should we avoid copying?
7. Does it create a collision risk with any candidate in this lab?
