# Research Workspace

This directory stores lightweight research memory, not a mirrored copy of the competition repository.

- `official-brief/` — canonical source pointers and change notes;
- `benchmarks/` — comparative notes on selected peer submissions;
- `fieldwork/` — field-observation plans and later cleared observations;
- `sources/` — external public-source index and provenance notes.

Large peer media, private data and non-cleared planning materials must not be committed here.
