# External Source Index

For each external source used in design reasoning, record:

- publisher / authority;
- title;
- canonical URL;
- publication and retrieval dates;
- geographic and temporal coverage;
- intended claim/use;
- license / reuse terms;
- transformations or calculations;
- known limitations;
- cross-check status when material.

Primary and current sources are preferred. A web result or community comment is a lead, not automatic authority.
