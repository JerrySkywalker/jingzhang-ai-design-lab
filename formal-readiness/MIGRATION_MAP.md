## Source migration plan

Normalize selected primary records into `sources.json`; keep `what_it_supports` ceilings in assumptions/risk text; link public pages; do not move third-party images/maps. Every quantitative claim needs a source or reproducible metric.

## Geometry plan

Start with current provisional constraints and their required flags. Build all nine topology-safe layers from the locked spatial framework; recompute metrics and figures; replace/recompute everything dependent on exact polygons when supplied.

## Figure plan

Create a shared semantic manifest for geometry IDs, metric IDs, labels and evidence status. Generate the five formal figure pairs plus board diagrams from that single source.

## Bilingual plan

Freeze glossary/IDs first; translate chapter by chapter; generate display pairs from shared data; verify numeric/reference parity mechanically and design language manually.

## Validation plan

Run each review incrementally; feature-freeze; regenerate all affected artifacts; finalize; marked self-check; participant preflight; exact-head final audit.
