# ADR-JZ100-0001 — Adopt Final 100 / Award Consolidation Program

**Status:** Accepted  
**Date:** 2026-08-30  
**Decision owner:** JerrySkywalker

## Context

The previous canonical program `JZ-97-CONVERGENCE-TRAIN-001` was created when the official merged baseline for 京张续城 / Jing-Zhang In Place was 77/100 and when calibration/high-water concerns still blocked direct score-lift work.

That state is now stale.

Since then, the project advanced through accepted official PRs. The current protected baseline is merged PR `open-city-ai/haidian#4270`, reviewed exact head `4cb6b1bd7407781d5121fc51ce81e6c8a06c1de1`, merge commit `e0927ba94154e3bf3b66c720f61560b9adba877b`, Trusted Review Agent score `93/100`, vector `5,5,5,4,5,5,4`, formal-review-ready and featured-candidate.

A final local read-only audit concluded that a credible 100/100 path exists if the project performs exactly two bounded lifts:

1. Implementation 4→5 through one integrated participant-authored S01 P0 pre-feasibility bridge.
2. Expression 4→5 through a real identity, deeper spatial typologies, a professional S01 plan/section/reset chain, A0 recomposition and intentional jury reading routes.

A parallel Owner/ChatGPT human-facing audit identified a separate award risk: the current gallery card, summary, report and visual experience read too much like an AI scoring/compliance package. The official gallery is currently using the deterministic fallback cover because the package has no participant `cover_image`; current summary and first-page information architecture are auditor-first; repository `visual_review.py` is not a pixel-level human visual review.

The Owner then approved a deeper humanistic doctrine:

- Public slogan: **让未来生长，让城市相续。**
- Humanistic thesis: **技术属于时代，城市属于世代。**
- City philosophy: **城市不是技术的容器，而是代际生活的连续体。**
- Three continuities: **续时 / 续生 / 续忆**
- Three temporal layers: **长久城市 / 可适应城市 / 暂居智能**
- Three key-area human states: **验证 / 共处 / 裁决**

## Decision

Adopt `JZ-FINAL100-AWARD-CONSOLIDATION-0830` as the new canonical active program.

The previous JZ97 Program is superseded for active admission and sequencing but remains immutable historical evidence.

The final program will execute exactly one long unattended successor-PR train with these simultaneous objectives:

1. Trusted Review Agent score **100/100** on a new exact head.
2. Later human professional-panel target `award-candidate`.
3. Make the first human impression unambiguously urban-design-first rather than audit/scoring-first.

Preferred execution topology is one sole writer, **Terra Ultra**, with Sol Ultra reserved for read-only architecture/Supervisor or as an explicitly configured single-writer substitute. Routine Owner interruptions are prohibited; only hard external blockers may stop the train.

## Consequences

### Positive

- Removes stale JZ97 calibration gates that no longer match the accepted 93-point reality.
- Makes the durable design-memory repository reflect current official truth.
- Combines machine-score closure with human award optimization instead of treating them as separate late tasks.
- Protects the five dimensions already scored 5/5.
- Creates one durable design doctrine and one executable unattended Goal rather than another collection of ad hoc chat instructions.

### Constraints

- No fabricated field evidence, partners, approvals, quotations or site precision.
- No broad redesign of geometry, scenarios, personas, regional interfaces or project-family counts merely for score gain.
- No control-plane/Goal files in the official submission subtree.
- No identical-head Review Agent rerolls.
- One final successor PR only; bounded same-PR exact-review repairs are permitted when tied to a real new deduction.
- An official Trusted Review score of 100 is required for Program success, but it is not an award claim.
