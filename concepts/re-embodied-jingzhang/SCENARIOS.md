## Personas — working minimum

1. young developer / startup member;
2. researcher / engineer;
3. resident family / caregiver;
4. older or mobility-limited resident;
5. service/logistics/frontline worker;
6. visitor / conference attendee.

## Scenario rule

Each final scenario card must eventually record:

`user → need → place → physical interface → AI function → required data → minimum sensing → operator → human review → degraded/fallback state → maintenance → evidence → risk`

If a scenario cannot define its fallback and maintenance path, it is not ready for the formal proposal.
