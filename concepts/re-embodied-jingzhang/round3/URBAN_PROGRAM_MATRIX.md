## Programme deletion rules

- If an ordinary civic/help/operations room meets the contract, delete the separate accountability pavilion.
- If an existing loading/maintenance bay supports safe holding and manual recovery, delete the new shared bay.
- If demands are coincident, low, very high or incompatible, prefer dedicated/specialised provision or no deployment.
- If two independent failure domains cannot fit, delete distributed sharing.
- If storage/wash/waste separation cannot fit, separate the task or reject co-location.
- If the space has no credible ordinary use at 80% lower demand, do not make it permanent.

## Result

Most physical programme is **good ordinary urban servicing**. C01’s contribution is the task-derived admission/segregation/allocation rule and a small removable interface layer. The candidate fails if it claims ordinary loading, staff rooms, maintenance or electrical rooms as new AI land use.
