## Ordinary-Day Completeness Gate

### Eight user groups and spatial corrections

| User | Weekday/evening/weekend issue | Heat/rain/event issue | Facility/digital-down issue | Spatial/operating correction |
|---|---|---|---|---|
| existing resident | through-route/event/noise may displace daily life | quiet and refuge can be lost to programmes | app/event closure can block help | permanent public route, quiet edge, free rest/refuge and resident appeal remain outside event/AI control |
| child/caregiver | care/toilet/waiting trip is chained | heat/rain and crowds amplify failure | lift/info outage strands group | toilets, seating, shade/rain refuge, step-free detour and staffed help located on ordinary route |
| older person | evening access/wayfinding and rest interval | heat/crowd/noise risk | digital-only booking/navigation excludes | frequent rest, high-legibility physical signs, human desk/phone and non-campus route |
| disabled person | weakest threshold determines trip | rain/flood/event barrier can erase nominal access | lift/door/digital outage needs equivalent path | audited redundant/assisted route, outage plan and stop condition before programmed opening |
| student/researcher | controlled campus/project hours differ from public city | events can conflict with study/quiet | secure system down must not close ordinary room | public-side rooms, separate controlled half, fixed schedule and ordinary learning fallback |
| enterprise/independent worker | small/secure work and daily services need different controls | event crowd can disrupt work/service | compute/access failure cannot strand tenancy | adaptable ordinary room baseline, reversible controlled state, service separation and manual allocation |
| maintenance/delivery worker | servicing is easily hidden behind public image | heat/rain/event reset increases exposure | access/scheduling system outage blocks work | surveyed service/emergency route, worker rest/toilet, manual key/handover and visible maintenance responsibility |
| visitor | arrival, heritage and public programme are easy to confuse | event/heat/rain requires clear refuge/exit | app-only route or closed campus creates dead end | gateway help, public-only route, clear opening status, physical map and cancellation fallback |
