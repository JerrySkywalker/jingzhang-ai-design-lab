# Round-3 Professional Admission Package

This package is a pre-design handoff, not a planning, architectural, transport, landscape or engineering conclusion.

## Admission question

Can C01's task-derived, bounded physical service layer be converted into credible urban form without displacing ordinary life, public space, landscape performance or conventional back-of-house functions?

The package asks professionals to test three conceptual sections and one common contextual base. It does not ask them to beautify a fixed concept.

## Evidence status

- `FACT`: official text, canonical rules and public source statements explicitly cited in the repository.
- `PROVISIONAL`: repository-supplied geometry that is not an official boundary.
- `CONTEXTUAL`: OSM/open-source observations used for topology and question formation only.
- `DERIVED`: reproducible output from stated inputs.
- `CONCEPT`: a design proposition requiring professional and field testing.

## Required return

Each reviewer should return: `ADMIT`, `ADMIT_WITH_CHANGES`, `REJECT`, or `CANNOT_DECIDE`, followed by the smallest spatial correction or missing evidence that controls the verdict. Reviewers should not infer ownership, statutory land use, population, capacity or construction feasibility from this package.
